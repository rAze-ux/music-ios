# Музыка — iOS-плеер с локальной медиатекой

Оригинальный плеер для iPhone (SwiftUI), вдохновлённый дизайном Apple Music: те же 5 вкладок, мини-плеер, полноэкранный экран «Сейчас играет», обложки, теги, плейлисты. Весь код, иконки и графика — оригинальные, написаны с нуля.

**Главная фишка:** приложение при первом запуске само создаёт папку **«Музыка»** внутри своих документов. Все файлы, которые вы туда кладёте (кнопкой «+» или по кабелю через Finder), автоматически сканируются: читаются теги (ID3v2.3/2.4 для MP3, метаданные M4A), вытягиваются обложки, собираются альбомы/артисты/жанры.

```
    ├── LibraryStore.swift       # сканирование папки, индексы, кэш
    ├── Metadata.swift           # AVAsset + парсер ID3v2
    ├── AudioPlayer.swift        # AVAudioPlayer, очередь, шаффл, локсрин
    ├── Theme.swift              # общие компоненты
    └── Assets.xcassets/         # иконка приложения
```

## Как получить .ipa (без Mac)

Приложение нельзя скомпилировать на Windows напрямую — iOS-сборка требует Xcode. Поэтому сборка делается бесплатно на серверах GitHub:

### Шаг 1. Загрузите проект на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com) (если аккаунта нет).
2. Нажмите **+ → New repository**, имя любое (например `music-ios`), **Public**.
3. На странице репозитория: **uploading an existing file** → перетащите **всю папку проекта** (браузер сохранит структуру подпапок). Дождитесь загрузки → **Commit changes**.

### Шаг 2. Запустите сборку

1. В репозитории откройте вкладку **Actions** → нажмите кнопку разрешения workflow, если спросит.
2. Слева выберите **Build IPA** → **Run workflow** → **Run workflow**.
3. Через 5–10 минут появится зелёная галочка. Откройте запуск → внизу **Artifacts** → скачайте **MusicApp-unsigned-ipa**.
4. Внутри архива — файл `MusicApp-unsigned.ipa`.

Если сборка упала — скачайте артефакт `build-log`, пришлите мне содержимое, я поправлю код.

### Шаг 3. Подпишите и установите на iPhone (Sideloadly)

1. Скачайте и установите на ПК: [Sideloadly](https://sideloadly.io), а также **iTunes** и **iCloud** с сайта Apple (именно десктапные версии, не из Microsoft Store).
2. Подключите iPhone кабелем, введите доверие на телефоне.
3. В Sideloadly: перетащите `MusicApp-unsigned.ipa`, введите свой Apple ID → **Start**.
4. На iPhone: **Настройки → Основные → VPN и управление устройством → [ваш Apple ID] → Доверять**.
5. Запускайте приложение.

> Бесплатная подпись Apple ID действует **7 дней** — просто повторно подпишите тем же Sideloadly (данные приложения сохраняются). Максимум 3 приложения на Apple ID. С платным аккаунтом разработчика ($99/год) подпись — год, или ставьте прямо через Xcode на Mac.

### Альтернатива — AltStore

Установите [AltServer](https://altstore.io) на ПК, AltStore на iPhone (через AltServer), затем в AltStore на телефоне: «+» → выберите `.ipa`. AltStore сам переподписывает каждые 7 дней при наличии Wi-Fi с ПК.

## Как добавить музыку

**Способ 1 — из самого приложения:** кнопка **+** в «Медиатеке» → выбрать файлы (MP3/M4A/WAV/FLAC/AIFF). Они копируются в папку «Музыка» приложения.

**Способ 2 — по кабелю через компьютер:**
1. Подключите iPhone к ПК, откройте Finder (Mac) или приложение **Apple Devices** / iTunes (Windows).
2. Выберите телефон → вкладка **Файлы** → приложение **Музыка**.
3. Перетащите песни/папки в окно — они попадут в общую папку.
4. В приложении свайпните вниз/перезапустите — медиатека просканируется сама.

Поддержка фонового воспроизведения и управления с экрана блокировки включена.

## Локальная сборка (если появится Mac)

```bash
brew install xcodegen
xcodegen generate
open MusicApp.xcodeproj
```
Выберите команду подписи в Signing → Run.

## Форматы

MP3 (с ID3v2-тегами и обложками), M4A/AAC, WAV, AIFF, FLAC, CAF. OGG/Vorbis iOS-плеер не декодирует.
